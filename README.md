## 🧠 Engineering Philosophy

My approach to engineering is centered around building systems that remain understandable and useful months after they’re written. I value:

- **Maintainability over cleverness:** Writing readable code that future developers (and my future self) can easily debug and scale.
- **Async-First Collaboration:** Thriving in globally distributed, remote environments with a heavy reliance on clear documentation, PR reviews, and autonomous workflow.
- **Developer Experience:** Building the internal tools, CLI utilities, and reusable hooks that make the rest of the engineering team faster.
- **Practical Problem Solving:** Focusing on software that solves real business bottlenecks—whether that's a dashboard, an API integration, or a recruitment automation pipeline.

## 🏗️ Open Source & Featured Projects

I strongly believe in the open web and public engineering. Here are a few key areas and projects I actively develop and maintain:

### WordPress Architecture & Plugins
- **CRM UTM Tracker:** A plugin designed to reliably capture, track, and pass UTM parameters into CRM lead forms for precise marketing attribution without data loss across redirects.
- **Async Queue Manager:** A background processing utility for handling heavy WordPress tasks asynchronously, preventing PHP timeouts and improving frontend performance.
- **Developer Hooks Toolkit:** A highly reusable, object-oriented PHP library that standardizes internal hook management across multiple client projects.
- **WP Component Library:** Reusable, modular UI components designed specifically for WordPress admin interfaces and custom blocks.

### Frontend Systems & Automation
- **Staffing Automation Tools:** An internal Node.js utility suite that automates candidate onboarding flows, integrates with external ATS APIs, and generates real-time notifications.
- **Figma Text-to-Image Plugin:** A TypeScript-based Figma plugin that generates seamless images directly on the canvas using external AI generative APIs, streamlining the design workflow.
